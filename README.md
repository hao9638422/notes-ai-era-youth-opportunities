## 概览

这是一期四个多小时的长访谈，主持人从"如果回到 20 岁、没有人脉和资源该怎么起步"切入，和孙宇晨聊了 AI 时代普通年轻人的机会。嘉宾的核心主张可以概括为三件事：第一，把生活和工作尽量"AI 化"——饮食、训练、睡眠、学习和决策都交给 AI 记录、分析、出日报，自己只做少量校准；第二，做决定前先"探图"——像玩即时战略游戏一样，先低成本收集大量信息（例如买房前先看一百套），再集中资源下注；第三，把健康（尤其是肌肉与心肺）当作长期战略的底层资产，因为身体垮了，其他一切都会被一票否决。在此基础上，他还谈到全球视角下的信息差与价差机会、把人类知识和货币"翻译给机器"（TRON / Crypto 的定位）、成功后保持"小我"（small ego）以持续更新认知、先自由后财富的正向循环，以及"先上路、先体验，再总结意义"和"多创造、少消费"的人生态度。
